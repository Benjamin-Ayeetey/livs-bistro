# Liv’s Bistro

A responsive food-business website inspired by Claude Type’s editorial pacing, expressive typography, rounded media and restrained navigation. Original layout and copy for Liv’s Bistro, using the supplied assets.

## Run

`npm install`, then `npm run dev`. Production: `npm run build`.

## Content and interactions

- Six sample meals with category filtering and dish detail dialogs.
- Enquiry builder with validation, editable review and copy-to-clipboard. No message, order or payment is sent.
- Responsive navigation, founder story, gatherings section and accessible FAQ.
- GSAP intro and section reveals, Lenis smooth scrolling, native reduced-motion experience. No Three.js: photography provides the focal experience.
- All photographs and the logo come from the user’s `assets` directory. Font families: Italiana and DM Sans self-hosted from Google Fonts with bundled open font licenses and system fallbacks. Interface icons: Solar via Iconify.

The business is Ghanaian and based in Accra, Ghana. The dish labels, Ghana cedi prices and `.example` contact are sample content. Replace these with confirmed business details before launch and connect the enquiry flow to a real ordering destination. The founder portrait is user supplied; story copy is proposed brand copy, not an attributed founder quote.

Design skills: build-awwwards-quality-sites and editorial-tech.
